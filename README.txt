SocialRain - zo zet je het online

Bestanden (10):
  Dockerfile, package.json, server.js, ctx.js, api.js, files.js, README.txt
  public/index.html, public/style.css, public/app.js

1. Zet ALLE bestanden in je GitHub-repo, in de hoofdmap. De map "public" moet erbij staan, met 3 bestanden erin.
2. Maak op Render een Web Service en kies Docker (het Dockerfile wordt gebruikt).
3. Video's en accounts staan in de map "data". Zonder Render Disk verdwijnen ze bij een nieuwe deploy.
